## 2. Вручную

Отмечайте по ходу; что не прошло — в раздел 18 ТЗ.

### Chrome или Edge, своя папка

- [ ] Первый запуск: выбор пустой папки → предложение заготовок → в папке появились `data.json`, `icons/`, `backups/`.
- [ ] Добавить Dota 2 из заготовок, назначить пару биндов, перезапустить браузер → бинды на месте, при необходимости экран «Разрешить доступ к папке».
- [ ] «Меню → Настройки»: сменить папку на пустую → данные и иконки перенесены; на папку с данными → «Открыть данные этой папки» и «Перенести текущие (заменить)».
- [ ] «Настройки → Резервные копии»: восстановить копию, текущие данные тоже легли в копию.
- [ ] Экспорт всего → импорт в чистый профиль браузера (или другой компьютер): данные и иконки совпадают.
- [ ] NFR-04: изменить что-то и сразу закрыть вкладку, пока статус «Сохранение…» — браузер предупреждает, `data.json` не повреждён.
- [ ] Вторая вкладка: плашка «Приложение уже открыто в другой вкладке», правки не применяются.

### Firefox

- [ ] Плашка «Данные хранятся в браузере», сценарии 2 и 3 из раздела 3.4 работают.
- [ ] Импорт перетаскиванием файла в окно.
- [ ] Известное исключение: боковые кнопки мыши в режиме проверки могут увести «Назад» / «Вперёд».

### Вид и удобство

- [ ] 3D и 2D, расцветка «Стандартная» и «Чёрная»: подписи читаются.
- [ ] Темы: светлая, тёмная, системная — смена темы Windows подхватывается без перезагрузки.
- [ ] NFR-08: назначение бинда — не больше 3 действий; «что на клавише» — одно действие.
- [ ] Окно 1280×720: шапка и полоса вида помещаются, ничего не обрезано.

### PWA на GitHub Pages

- [ ] Установить приложение из адресной строки Chrome или Edge, открыть ярлыком: своя иконка, отдельное окно, размер окна запоминается.
- [ ] NFR-01: DevTools → Network, первая загрузка не дольше 2 с, повторная из кэша — не дольше 1 с.
- [ ] Офлайн: отключить сеть, открыть приложение — работает (кроме загрузки иконок Steam).
- [ ] После следующего деплоя появляется плашка «Доступна новая версия», «Обновить» перезагружает на новую версию без потери несохранённого.
